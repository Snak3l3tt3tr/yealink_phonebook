Routine Maintenance

  • Keep a current CSV backup outside the Docker host.
  • Update with docker compose up -d --build.
  • Review problems with docker compose logs --tail 100 phonebook.
  • Do not delete the phonebook-data volume unless you intend to erase the database.

Change Administrator Password

Use at least 8 characters. Changing the password signs out every active session.

Security: Web management requires an administrator login. The Yealink XML URL remains public so phones can synchronize; use HTTPS and restrict network access where possible.
